# 🌱 스프링 (Spring)

> 가족을 품은 온기로 피워낸 봄, 이제는 그대의 봄을 향해 도약하도록, **Spring**

가족돌봄청소년·청년을 위한 **원스톱 공공복지 AI 안내 서비스**의 챗봇 프로토타입입니다. 신청 전 사전 상담부터 사후 돌봄기록서 작성까지, 자연스러운 대화로 행정 부담을 덜어주는 것을 목표로 합니다.

공식 서비스 기획안은 [`docs/spring-service-spec.md`](docs/spring-service-spec.md)를 참고하세요.

---

## 주요 기능

- **🌷 사전 상담** — 가입 정보(이름·생년월일·거주지)를 받아 만 나이·지역·간편인증 가능 여부로 적용 라우트를 자동 판별하고, AI 상담사가 친근한 대화로 돌봄 실태를 파악해 **사전 맥락 보고서**를 자동 작성합니다.
- **🍃 사후 관리** — 매월 돌봄기록서 작성을 대화로 진행합니다. 영수증 사진을 올리면 항목/금액을 추출해 고부담형(월 40만 원) 유지 기준을 자동 체크하고, 거주지 변동 시 자격 영향까지 안내합니다.
- **🎙️ 음성 입출력** — 마이크로 답하거나 텍스트로 입력 모두 가능합니다. AI 응답은 한국어 음성으로 자동 재생됩니다.
- **🚨 위기 신호 자동 감지** — 자해·학대·방임 등 신호가 보이면 즉시 1393(자살예방)·1577-1391(노인보호)·1366(여성긴급)·112·120 연락처를 안내합니다.

## 라우팅 정책

가입 시점에 자동 판별합니다.

| 조건 | 라우트 | 다음 단계 |
| --- | --- | --- |
| 만 9~13세 | Route A | 법정대리인과 동주민센터·구청 방문 |
| 만 14~39세 + 서울 + 간편인증 가능 | Route B | 서울복지포털 온라인 신청 |
| 만 14~39세 + 인천·울산·충북·전북 | Route B | 청년ON 온라인 신청 |
| 39세 초과·제대군인·간편인증 불가 | Route A | 구청 방문 |
| 그 외 | 지원 대상 외 | 안심돌봄120(서울) 등 대체 자원 안내 |

## 기술 스택

- **Python 3.13** + [Streamlit](https://streamlit.io/) — 단일 파일 데모
- **Google Gemini 2.5 Flash** (`google-genai` SDK) — 멀티모달 챗 + tool calling
- **gTTS** — 한국어 음성 합성
- **python-dotenv** — 환경 변수 로딩

## 실행 방법

### 1. Gemini API 키 발급

[Google AI Studio](https://aistudio.google.com/apikey)에서 무료로 발급합니다.

### 2. 환경 설정

```bash
# 의존성 설치
.venv/bin/pip install -r requirements.txt

# API 키 설정
cp .env.example .env
# .env 파일을 열어 GEMINI_API_KEY=... 값을 채워 넣으세요
```

### 3. 실행

```bash
.venv/bin/streamlit run app.py
```

브라우저가 자동으로 열리지 않으면 터미널에 출력된 `http://localhost:8501` 주소로 접속하세요.

## 데모 범위

이 프로젝트는 **단순 데모**입니다.

- 영구 저장소·로그인 시스템 없음 — 세션 메모리만 사용
- 정부 발굴 시스템·공식 포털 API 연동 없음 — 라우팅 결과 안내까지만
- VLM 서류 사전 검토는 미구현 (영수증 이미지는 Gemini 멀티모달이 직접 읽음)

기획안 4단계 중 어떤 부분이 데모에 포함되고 어떤 부분이 제외되는지는 [`docs/spring-service-spec.md`](docs/spring-service-spec.md)와 [`CLAUDE.md`](CLAUDE.md)에서 확인하세요.
